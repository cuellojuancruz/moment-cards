# Moment Cards

Crear la primera versión funcional de “Momento”, una app web premium y mobile-first para crear y compartir tarjetas digitales interactivas. Incluir landing emocional con CTAs “Crear mi tarjeta” y “Ver ejemplo”; editor modular de 5 pasos (ocasión, personalización, fotos locales/mock con previews/reordenar/eliminar, estilos visuales, previsualización); y experiencia pública en /t/:id donde el destinatario abre un sobre animado, ve revelación Para/De parte de, mensaje progresivo, galería de fotos animada y final con replay/crear tarjeta. Preparar arquitectura React+TypeScript limpia y modular, capa de datos local/mock preparada para reemplazar por Supabase, temas configurables y demo de cumpleaños para Martina de Juan con el texto indicado e imágenes ejemplo. Priorizar diseño cinematográfico cálido, elegante, moderno y animaciones fluidas con Framer Motion; sin pagos, auth ni funciones complejas.
